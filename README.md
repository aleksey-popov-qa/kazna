# Казна

Управленческий учёт денег по мотивам Adesk: счета, операции, платёжный календарь с прогнозом кассовых разрывов, отчёты ДДС и ОПиУ, доходность проектов.

## Как запустить у себя

Нужен [Node.js](https://nodejs.org) версии 18 или новее. Больше ничего ставить не надо: у сервера нет зависимостей.

```
git clone <адрес репозитория>
cd kazna
node server.js
```

Сервер напечатает ссылку вида `http://127.0.0.1:8787/?k=...`. Откройте её в браузере.

- При первом запуске в базу заливаются демо-данные: условная кофейня с доставкой за июль–ноябрь 2026 года. Убрать их можно кнопкой «Удалить примеры» на сводке. Счета и типовые статьи останутся.
- Данные хранятся в `data/db.json`, ключ доступа в `data/key.txt`. Папка `data/` в репозиторий не попадает, у каждого своя.
- Начать с чистого листа: остановить сервер (Ctrl+C), удалить `data/db.json`, запустить снова.
- Другой порт: `PORT=9000 node server.js` (в Windows: `set PORT=9000` и затем `node server.js`).
- По умолчанию сервер виден только с этого компьютера. Открыть в локальной сети: `HOST=0.0.0.0`.

## Что внутри

| Путь | Что это |
|---|---|
| `kazna.html` | Всё приложение одним файлом: разметка, стили, скрипт |
| `server.js` | Сервер: отдаёт страницу, хранит данные в JSON-файле, пускает по ключу |
| `seed/seed.js` | Генератор демо-данных: 2 счёта, 17 статей, 2 проекта, 5 контрагентов, 90 операций |
| `seed/batch*.json` | Демо-данные, которые сервер заливает при первом запуске |
| `seed/docs/` | Те же операции по файлу на запись |

## Разделы

- **Сводка**: остаток на счетах, поступления, выплаты и прибыль за месяц, график остатка с прогнозом на 60 дней, ближайшие платежи.
- **Операции**: поступления, выплаты и переводы, проведённые и плановые, фильтры и поиск, импорт и экспорт CSV.
- **Платёжный календарь**: поступления, выплаты и остаток на конец каждого дня, красным отмечены дни с отрицательным прогнозом.
- **Отчёты**: ДДС, ОПиУ и проекты за год по месяцам.
- **Справочники**: счета, статьи, проекты, контрагенты.

## Версия на claude.ai

Та же страница опубликована артефактом на claude.ai: https://claude.ai/artifact/1AFAsuBkyhVYtT4BeH4i9v. Открыть её могут только те, с кем владелец поделился. Там данные хранятся в базе claude.ai, с `server.js` они не синхронизируются. Страница сама понимает, где запущена: на claude.ai берёт базу оттуда, иначе обращается к `server.js`.

Перепубликовать изменения в артефакт нужно с тем же URL, иначе создастся новая страница с пустой базой.
